# Horror Escape Room Game Planning

## 1. 게임 개요

| 항목        | 내용                            |
| --------- | ----------------------------- |
| 게임 제목     | **Escape Room**               |
| 장르        | Horror / Escape Room / Puzzle |
| 개발 엔진     | Unreal Engine 5               |
| 플랫폼       | PC                            |
| 플레이 방식    | Single Player                 |
| 시점        | First Person                  |
| 예상 플레이 시간 | 10~15분                        |

### 한 줄 소개

> 10분마다 죽음과 유령이 반복되는 폐교에서 희생과 협력을 이용해 탈출하는 호러 퍼즐 게임

---

## 2. 게임 컨셉

플레이어는 학생이고 평화로운 일상을 지내던 중 갑자기 괴현상이 일어난다.

학교 안에서는 학생들이 하나씩 사라지기 시작하며, 각 학생에게는 **10분의 제한 시간**이 주어진다.

학생이 죽으면 게임이 끝나는 것이 아니라 **유령으로 변하여 일정 시간 동안 학교에 남게 된다.**

유령은 살아있는 학생이 할 수 없는 특정 행동을 수행할 수 있으며, 이를 이용해 다음 학생의 퍼즐을 해결하고 탈출을 진행한다.

### 핵심 키워드

* **Explore** : 폐교 탐색
* **Puzzle** : 퍼즐 해결
* **Sacrifice** : 학생의 희생을 이용한 진행
* **Ghost** : 죽은 학생의 유령 활용
* **Escape** : 최종 탈출

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 학교 내부를 탐색한다.
2. 퍼즐을 해결하여 다음 구역으로 이동한다.
3. 필요한 경우 학생을 희생시킨다.
4. 죽은 학생의 유령을 이용하여 퍼즐을 해결한다.
5. 학교에 숨겨진 사건의 진실을 찾는다.
6. 최종 탈출구를 열고 학교에서 탈출한다.

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
탐색
  ↓
퍼즐 발견
  ↓
단서 획득
  ↓
퍼즐 해결
  ↓
다음 구역 이동
  ↓
학생 사망 / 희생
  ↓
유령 등장
  ↓
유령 능력 활용
  ↓
다음 퍼즐 해결
  ↓
탈출
```

플레이어는 **탐색 → 퍼즐 해결 → 희생 → 유령 활용 → 이동**의 과정을 반복하며 게임을 진행한다.

## 5. 플레이어 조작

| ------------- | ----------------- |

---

## 6. 플레이어 기능

### 6.1 이동

플레이어는 FPS 방식으로 폐교 내부를 자유롭게 이동할 수 있다.

주요 기능:

* 앞으로 / 뒤로 이동
* 좌 / 우 이동
* 마우스 시점 회전
* 점프
* 달리기

### 6.2 상호작용

플레이어는 주변의 다양한 오브젝트와 상호작용할 수 있다.

* 문 열기
* 열쇠 획득
* 서랍 조사
* 책 및 문서 조사
* 스위치 작동
* 퍼즐 해결

### 6.3 10분 제한 시간

각 학생에게는 **10분의 제한 시간**이 존재한다.

제한 시간이 끝나면 해당 학생은 사망하며 유령 상태로 전환된다.

### 6.4 유령 시스템

사망한 학생은 일정 시간 동안 유령으로 남는다.

유령은 특정 오브젝트와 상호작용하거나 살아있는 학생을 도와 퍼즐을 해결할 수 있다.

예:

* 압력판 밟기
* 스위치 작동
* 특정 장애물 통과
* 문 개방 보조

---

## 7. 주요 퍼즐

| 구역  | 퍼즐 내용              |
| --- | ------------------ |
| 교무실 | 출석부를 이용한 번호 퍼즐     |
| 도서관 | 책과 단서를 이용한 비밀번호 퍼즐 |
| 교실  | 시계 및 칠판 단서 조사      |
| 방송실 | 스위치 순서 퍼즐          |
| 지하실 | 사건 기록을 이용한 최종 퍼즐   |

---

## 8. 게임 클리어

모든 퍼즐을 해결하고 최종 탈출구를 개방한 후 학교 밖으로 탈출하면 게임이 종료된다.

```text
퍼즐 해결
  ↓
최종 열쇠 획득
  ↓
탈출구 이동
  ↓
문 개방
  ↓
학교 탈출
  ↓
GAME CLEAR
```
